# Aurora — SQL & Power BI Analytics

## Project Overview

Aurora is a data analytics project demonstrating data preparation, SQL analysis, KPI calculations, and interactive business reporting using Power BI.

The project focuses on transforming a dataset into structured analysis and presenting relevant business metrics through a dashboard.

## Tools & Technologies

- **SQL:** Data analysis, aggregation, KPI calculations, and churn-rate analysis.
- **Power BI:** Data visualization, dashboard development, and business reporting.
- **Data preparation:** Cleaning, validation, and calculation checks.

## Project Workflow

1. Reviewed and cleaned the dataset.
2. Prepared the data for analysis.
3. Developed SQL queries to investigate business metrics, including churn rate.
4. Calculated and reviewed key performance indicators.
5. Built and refined an interactive Power BI dashboard.
6. Prepared documentation and visual evidence of the analysis.

## Key Deliverables

- SQL analysis scripts
- Cleaned dataset, where permitted
- Power BI dashboard and supporting screenshots
- Project documentation and analysis notes
